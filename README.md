
# SAMD21 学习笔记

> **芯片**：ATSAMD21G18A（Cortex-M0+ @48 MHz，256 KB Flash，32 KB SRAM，**48 脚 / 38 个 I/O**）
> **工具链**：MPLAB X IDE 6.30 + XC32 5.10 + SAMD21_DFP 3.7.262

## 一颗 MCU 是怎么运转的（全书主线）

所有外设都长在一条通路上：

```text
外部世界 ──▶ 引脚(PORT) ──▶ 外设(SERCOM/TC/ADC…) ──▶ 总线 ──▶ 内存 / CPU
```

而不管用哪个外设，都要经过同样四个**横切系统**——它们与具体外设无关，是整颗芯片的公共设施：

| 横切系统 | 它回答的问题 | 在哪一章 |
|---|---|---|
| 电源 | 有没有电、什么时候复位 | 第 1、6 章 |
| 时钟 | 谁在走时（振荡器 → GCLK → PM 门控） | 第 5 章 |
| 引脚 | 谁连到外面（PINCFG / PMUX / EIC） | 第 4 章 |
| 事件与中断 | 谁能通知谁、数据谁来搬 | 第 11、12 章 |

外加两块地基：**寄存器怎么读写**（第 2 章）、**工程怎么建、程序从哪开始跑**（第 3 章）。

由此得到贯穿全书的公式：

> **一个外设能用 = 开总线时钟 + 分配通用时钟 + 配引脚 + 配功能寄存器。**

第 2 章把这条公式讲透，后面每章只是把它套到具体外设上。

## 阅读约定

- 代码默认 **MPLAB X + XC32 + SAMD21_DFP 3.7.262**；寄存器宏名以 DFP 头文件为准，个别宏名不同版本会有差异，正文会标出来。
- 「复位默认」指手册里该寄存器的 Reset 值；芯片复位后主频只有 **1 MHz**（OSC8M ÷ 8），要 48 MHz 得自己配（第 5 章）。
- 手册引用写成"章号.小节号"，例如 23.6.3，对应数据手册 DS40001882。
- 每章结尾都有**思维模型图**、**最重要的几句话**和**自测**，自测的答案都能从正文推导出来。

## 术语最小集

| 术语 | 一句话解释 |
|---|---|
| 桥 A / B / C | 三条外设总线，基址 `0x40000000` / `0x41000000` / `0x42000000`，各 64 KB |
| APB 时钟 | 决定"你能不能读写这个外设的寄存器" |
| 通用时钟（GCLK） | 决定"这个外设自己走不走时"，共 9 个发生器 |
| PMUX / PINCFG | 把引脚交给外设、以及配置引脚属性的开关 |
| PAC | 外设寄存器写保护，不解锁写不进去还会触发异常 |
| SYNCBUSY | 跨时钟域的写入还没生效，要等它变 0 |
| 三态 / 悬空 | 引脚既不接 VDD 也不接 GND，电平不确定 |

## 关于代码

- 所有代码都按 **SAMD21_DFP 3.7.262 的平铺写法**书写：`PORT_REGS->GROUP[0].PORT_DIRSET`、`SERCOM0_REGS->I2CM.SERCOM_CTRLA`、`GCLK_REGS->GCLK_CLKCTRL`。网上大量教程用的是 ASF 时代的 `PORT->Group[0].DIRSET.reg`，**在本地这套 DFP 下编译不过**；各章都附了新旧写法对照表。
- 各章的主要例程都经过编译验证，命令是：

```text
pic32c-gcc -mcpu=cortex-m0plus -mthumb -Wall -Wextra ^
  -I "C:\Program Files\Microchip\MPLABX\v6.30\packs\Microchip\SAMD21_DFP\3.7.262\samd21a\include" ^
  -D__SAMD21G18A__ -c 你的文件.c
```

- 编译报"找不到 `SystemCoreClock`"时，看附录 14.13 第 6 条（`sam.h` 不会自动带进 `system_samd21g18a.h`）。
- 手册、工具链里那些**看起来矛盾或容易踩的地方**，统一收在 [ch14-appendix.md](SAMD21笔记-14-附录速查.md) 的 **14.13 手册与工具链的已知坑**，遇到"手册和代码对不上"先去那里看一眼。

## 这套笔记的边界

- 只讲 **ATSAMD21G18A**（48 脚）这一颗，不覆盖 DA1、D51、L21 等兄弟型号；家族差异在需要处会点明。
- 深入程度：**寄存器级**，不依赖任何代码生成器（Atmel START / Harmony 未安装、也未使用）。
- 例程都在 MPLAB X 6.30 + XC32 5.10 下验证过编译；**没有上板实测**，需要实测的地方（功耗、时序、波特率误差）正文都标注了。
